# AGENTS.md

## Процесс
- Один запрос пользователя = один этап из `PLAN.md`. Следующий этап только по новому запросу.
- Работать строго по `PLAN.md`, отмечать выполненные пункты чекбоксами в том же коммите.
- Перед коммитом прогонять: `cargo fmt --check`, `cargo build`, `cargo clippy -- -D warnings`, `cargo test`.
- В конце этапа делать коммит с осмысленным сообщением.
- Если `git remote` задан — пушить. Если нет — явно сообщить, что пуш пропущен.
- После этапа выдавать пользователю короткую инструкцию: что запустить и что именно проверить.

## Код
- Никаких комментариев в коде.
- Файл до ~400 строк; при росте делить на подмодули.
- Абстракция только при двух и более реальных потребителях.
- Ошибки через `thiserror`/`anyhow`; никаких `unwrap()` в путях рантайма.
- Горячие пути без аллокаций; буферы переиспользовать.
- Новые зависимости добавлять только с обоснованием в сообщении коммита.

## Границы
- Цель — свои offline-mode серверы. Online-mode с шифрованием не реализуется.
- Обход античитов и маскировка клиента не реализуются.
- Одиночная игра не реализуется.
- В UI клиента не использовать слова Minecraft и Hypixel.
- Ассеты (текстуры, модели, звуки) не коммитить; только загрузка при первом запуске в кэш.
- `ref/` — только чтение, не изменять и не коммитить изменения в нём.
- Секреты и токены не коммитить.

## Эталон
- Поведение, физика и протокол сверяются с `ref/` и `ref/protocol-47.json`.
- Формат — протокол 47, версия 1.8.9.
